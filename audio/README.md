# 배경음악 넣는 곳

이 폴더에 파일을 넣으면 합성 칩튠 대신 그 파일이 재생됩니다.
아무것도 없으면 `src/audio.js`가 그 자리에서 만들어내는 칩튠이 나옵니다.

| 파일 | 언제 나오나 |
|---|---|
| `intro.mp3` | 인트로 화면 |
| `stage.mp3` | 플레이 중 (스테이지가 올라갈수록 재생 속도가 빨라집니다) |
| `ending.mp3` | 최종 엔딩 |

`.mp3` · `.ogg` · `.wav` · `.m4a` 순서로 찾습니다. 세 개를 다 넣을 필요는 없고,
넣은 것만 파일로 나가고 나머지는 칩튠으로 나갑니다.

<br>

## 올리기 전에

이 폴더는 `.gitignore`에 걸려 있어 **저장소에 올라가지 않습니다.** 일부러 그렇게 두었습니다.

이 게임은 공개 저장소에 있고 GitHub Pages로 배포됩니다. 즉 여기 넣은 파일은
저장소에 커밋하는 순간 전 세계에 배포됩니다. 유튜브에서 뽑은 음원, 게임·애니메이션
BGM, 가요 같은 것은 비상업이라도 배포하면 저작권 침해입니다.

배포까지 하려면 그럴 권리가 있는 음원이어야 합니다.

- **Pixabay Music**, **Incompetech**(Kevin MacLeod, CC BY), **OpenGameArt**,
  **Free Music Archive** — 출처 표기 조건만 지키면 되는 것이 많습니다
- **YouTube 오디오 보관함** — 유튜브 스튜디오에서 받을 수 있고 라이선스가 명시됩니다
- 직접 만든 곡

CC BY 음원을 쓴다면 저작자 표기를 README와 엔딩 크레딧에 넣어야 합니다. 곡을
정하시면 표기까지 같이 넣어드리겠습니다.
